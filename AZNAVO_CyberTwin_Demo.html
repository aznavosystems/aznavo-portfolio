Ordre conseillé pour le pilote
1. Tester l'app et les rôles avec données fictives.
2. Installer Wazuh dans un environnement de test.
3. Créer un compte API en lecture seule et stocker son secret côté serveur.
4. Importer quelques alertes, vérifier l'isolation entre sociétés, puis faire valider par un testeur externe.
